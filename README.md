# Character-Tokens-v3.0

A set of 256 x 256 pngs with alpha masks for use as Character Tokens in Mume. These are all head and shoulders.
There's also full/part body images for most mounts and common charmies/familiars.

This should cover most race, class and gender combinations - and many subraces where I felt I had an idea of what to do.
There are probably a few double ups too, but I figure it's just more options.

Ideally, just pick whatever you like for your character.

Naming for characters is [race]-[gender - M or F]-[Class/descriptor] -[anything else to identify, not always used]. A number is at the end of more than one exist.

So - Hobbit-M-Warrior-Weathered-1.png

Mounts are Mount-[species]-[descriptor]- [number].
So Mount-Horse-Rohir-1.png.

Charmies/familiars/mobs are Mob-[species]-[descriptor]-number]

So Mob-Orc-Lithe.png.

These were made prompting chatgpt - initially in a renaissance painting style (version 2, which isn't uploaded), which was later used as the basis of a comic style remake of each.
